CrowdSec Cloudflare List Bouncer
View on GitHub Download GPG Key

Official APT and RPM package repository for Debian, Ubuntu, Enterprise Linux, and Fedora.

Synchronizes CrowdSec LAPI decisions into Cloudflare Account-level IP Lists to block malicious traffic at the Cloudflare edge before it reaches origin infrastructure.

Tip: If running as root, you may omit the sudo command prefix.

Debian / Ubuntu

APT repository for supported Debian, Ubuntu, and derivative releases (amd64, arm64)

Create keyring directory

Ensures the standard standalone APT keyring directory exists with secure permissions.

bash 
sudo install -m 0755 -d /etc/apt/keyrings
Install repository signing key

Downloads and stores the official OpenPGP key to verify package integrity.

bash 
curl -fsSL https://webstudiobond.github.io/crowdsec-cloudflare-list-bouncer/webstudiobond.gpg | sudo tee /etc/apt/keyrings/webstudiobond.gpg > /dev/null
Add APT repository source

Configures the repository entry bound to the verified signing key.

bash 
echo "deb [signed-by=/etc/apt/keyrings/webstudiobond.gpg] https://webstudiobond.github.io/crowdsec-cloudflare-list-bouncer/deb stable main" | sudo tee /etc/apt/sources.list.d/crowdsec-cloudflare-list-bouncer.list
Update package index

Refreshes local APT cache with package metadata from the new repository.

bash 
sudo apt update
Install the bouncer

Installs the package and sets up the systemd service unit.

bash 
sudo apt install crowdsec-cloudflare-list-bouncer

RHEL / Fedora / CentOS / AlmaLinux

RPM repository for supported Enterprise Linux (RHEL, AlmaLinux, Rocky), Fedora, and derivative releases (x86_64, aarch64)

Add repository configuration

Creates the repository file with GPG package and repository metadata checking enabled.

bash 
sudo tee /etc/yum.repos.d/crowdsec-cloudflare-list-bouncer.repo << 'EOF'
[crowdsec-cloudflare-list-bouncer]
name=CrowdSec Cloudflare List Bouncer
baseurl=https://webstudiobond.github.io/crowdsec-cloudflare-list-bouncer/rpm/
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://webstudiobond.github.io/crowdsec-cloudflare-list-bouncer/webstudiobond.gpg
EOF
Install the bouncer

Installs the package via DNF (or YUM). The GPG key is imported automatically on first run.

bash 
sudo dnf install crowdsec-cloudflare-list-bouncer
